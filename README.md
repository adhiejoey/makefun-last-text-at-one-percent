Entry for the make.fun bounty **Last Text at One Percent** (`u-azazex-last-text-at-one-percent-ba9fc876`).

`main.ts` writes a single file, `entry.txt`, to the output directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`). The entry is one line of plain ASCII text — the final text message a dying phone sends at 1% battery, in the phone's own voice: petty, secret-keeping, and cut off mid-word as the battery gives out.

Run it with plain `node main.ts` (Node 22+, standard library only, no network).
